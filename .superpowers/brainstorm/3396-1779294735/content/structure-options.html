В — Дашборд + детали

Первая страница — общий дашборд объекта. Следующие 4 страницы — детальные листы для каждой роли. Директор смотрит только стр.1, рабочий — только свою страницу.

Для нового объекта нужно изменить только исходные данные — всё остальное пересчитается автоматически.
