- что делает каждая из 3 бригад конкретный день

## 6. Технические параметры HTML

- Самодостаточный HTML без внешних зависимостей (всё inline CSS + JS)
- Цветовая схема: белый фон, #1b5e20 зелёный акцент (как montage.html и calc.html)
- @page A4 landscape для печати
- @media print: скрыть кнопку, сохранить цвета ячеек
- Кнопка «🖨 Сохранить PDF» — как в других файлах
- Строки-разделители недель: жирный зелёный фон
- Контрольные точки: особая строка красно-оранжевого цвета
- Материальный блок в каждой строке дня: компактный список с иконками ✅ ⚠ ❌
