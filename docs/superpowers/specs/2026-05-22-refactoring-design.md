# Рефакторинг 4S Grape Garden Dashboard

**Дата:** 2026-05-22  
**Проект:** vineyard-deploy  
**Цель:** Одна ссылка, данные в JSON, код по частям

---

## Контекст

Проект — статический HTML-дашборд системы орошения 4S Grape Garden (56,7 га, Крым).  
Деплой: GitHub Pages (`git push`).  
Рабочий каталог: `C:\Users\user\Desktop\vineyard-deploy\`

Текущие проблемы:
- 8 отдельных HTML-файлов — несколько ссылок, неудобно
- `index.html` ~326 кб, 13 вкладок в одном файле — трудно найти нужное место
- CSS и JS продублированы в каждом файле
- Финансовые данные, состав бригады, статусы материалов захардкожены в HTML

---

## Главное решение: одна ссылка

Всё содержимое 8 файлов переезжает в один `index.html`.  
Текущие отдельные страницы становятся вкладками в боковом меню.  
Старые файлы (`docs.html`, `daily.html` и др.) удаляются.

**Единственная ссылка:** https://dimaborisov410-coder.github.io/4s-grape-garden/

## Сборщик (build.js)

Node.js скрипт:
1. Читает `src/shared/style.css`
2. Читает все JSON из `src/data/`
3. Читает все вкладки из `src/tabs/` (19 файлов)
4. Собирает один `index.html`:
   - Вставляет общий CSS
   - Добавляет все вкладки в боковое меню
   - Инжектирует данные как `window.DATA`
   - Собирает тело страницы

## Как меняется процесс обновления

| Было | Стало |
|------|-------|
| Несколько ссылок | Одна ссылка |
| Ищу место в 3000+ строках | Открываю нужный файл вкладки |
| Обновляю финансы — риск сломать HTML | Меняю цифру в `finance.json` |
| Общие стили в 8 местах | В одном `style.css` |

Деплой остаётся прежним: `update.bat`

## Ограничения

- Никаких фреймворков, только Node.js (уже установлен)
- Финальный `index.html` самодостаточен (не подгружает JSON в браузере)
- Визуальный результат идентичен текущему
- Старые прямые ссылки (`/daily.html` и др.) перестанут работать — заменяются якорями внутри одной страницы
